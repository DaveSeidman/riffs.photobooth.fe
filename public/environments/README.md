# Bottle button studio environment

`studio_small_03_1k.hdr`: Studio Small 03 by Greg Zaal, Poly Haven, CC0.
Source: https://polyhaven.com/a/studio_small_03
Download: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/studio_small_03_1k.hdr

Bundled locally for offline kiosk use. The two bottle buttons share the loaded HDRI for environment lighting and reflections. The HDRI is dimmed and used only for lighting/reflections. Transmission passes use a near-black (#030207) background so the studio does not appear gray through the glass. Pink/violet rim lights and a subtle silhouette glow define the edges; the surrounding canvas stays transparent over the circular button frame.
